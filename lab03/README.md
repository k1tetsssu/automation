# Lab 03: Task Scheduler (Cron) Automation

В этой лабораторной работе настроен Docker-контейнер на базе Ubuntu, который использует `cron` для автоматического запуска Python-скрипта получения курсов валют по расписанию.

## Структура проекта

* `currency_exchange_rate.py` — скрипт из Lab 02 для получения курсов валют через API.
* `cronjob` — файл с настройками расписания задач (расчет "вчерашней" и "прошлонедельной" даты происходит динамически через утилиту bash `date`).
* `Dockerfile` — инструкции для сборки образа (установка `cron`, `python3`, `requests`, копирование файлов и настройка прав).
* `entrypoint.sh` — стартовый скрипт, который экспортирует переменные окружения, создает лог-файл и запускает `cron` в фоновом режиме.
* `docker-compose.yml` — конфигурация для удобной сборки и запуска контейнера.

## Сборка и запуск контейнера

1. Убедитесь, что основной API-сервер запущен.
2. Откройте терминал в папке `lab03` и выполните команду:

```bash
docker-compose up -d --build
```
3. Чтобы убедиться что всё работает как надо, можно посмотреть логи контейнера:
```bash
docker-compose logs -f
```

Если видно строчки вида:

```bash
lab03_cron_worker  | Creating log file...
lab03_cron_worker  | Log file created at /var/log/cron.log
lab03_cron_worker  | === Starting cron daemon ===
lab03_cron_worker  | === Monitoring cron logs ===
```

Значит, скрипт entrypoint.sh успешно отработал, и cron сидит в фоне, ожидая наступления нужного времени (6 утра или 17:00 пятницы), чтобы запустить скрипт. Чтобы выйти из просмотра логов, нажмите `Ctrl + C` в терминале
